# Dossier project instructions

- Read `dossier.project.json`, `data/pages/project-home.json`, `data/pages/current-state.json`, and `data/roadmap.json` before project work.
- Treat this folder as the durable project record shared by the owner and agents.
- Use this Dossier for durable roadmaps, requirements, design decisions, review evidence, implementation handoff, and documentation that must outlive one conversation.
- Update an existing canonical page before creating another page for the same durable purpose. One-off explanations and scratch notes do not need a new canonical page.
- Keep project direction, requirements, design, implementation evidence, evaluation, and owner decisions distinct.
- Agents may prepare proposals and evidence, but the project owner retains direction and approval authority.
- When the owner asks to check Agent Requests in Notes, use the connected runtime's read-only Agent Request scanner first. Treat request blocks as human-owned intent, not permission to execute or approve work.
- Use the connected shared Dossier Engine runtime; do not copy runtime source or dependencies into this portable project folder.
- Open or validate this project through the shared runtime. Do not launch a graphical window unless the owner requests it.
- Do not rewrite project data for a runtime update without an explicit migration preview, backup, report, and owner approval.

Add a short instruction to the parent repository's AGENTS.md telling agents to read `dossier/AGENTS.md` when this folder is named `dossier`.
