# T300 handover, updated 2026-08-06

This is the current restart point for the T300 software work. It is written so
another agent can continue after chat compaction without guessing.

## Most important state

The physical T300 is still on the restorable Comgrow/Sovol firmware `1.5.2`
with patched Klipper `0.12.0`. Nothing from `mainline/` has been installed on
the printer, written to eMMC, flashed to either MCU, or used to command
movement or heat.

The mainline work in this repository is a laptop-side, commissioning-locked
candidate. Treat it as implementation and test preparation only.

Do not run heavy Klipper harnesses again unless the user explicitly asks. The
previous long harness runs completed successfully, but the user later saw the
Codex/code session crash twice and rebooted the PC. Use the saved validation
evidence and lightweight checks first.

## User priorities

- Protect hardware above every convenience feature.
- Do not weaken upstream Klipper sensor, thermal, motion, endstop, probe, MCU,
  watchdog, or emergency-stop behavior.
- Community-proven behavior is preferred. Custom code is allowed only when the
  T300-specific risk has no robust community solution and the design is audited.
- The owner initiates every power, bootloader, disk write, MCU flash, movement,
  heat, calibration, and print action.
- The private purchased GerGo package is allowed for personal use but must not
  be committed, quoted, uploaded, or replaced by an unofficial copy.
- Use Orca-supported slicing/profile features. Do not hand-edit model meshes or
  final G-code for print quality.

The mainline candidate uses pinned Armbian, Klipper, Moonraker, Mainsail,
Crowsnest, KAMP, and timelapse sources from `stack.lock.json`. The physical
screen preserves the exact Comgrow 1.5.2 serial-TFT firmware and bridge behind
an unprivileged compatibility gateway instead of using KlipperScreen.
Mainsail is staged from the official compiled `v2.18.2` release artifact, not
from development source.

The production Klipper extra is:

```text

```

It is a policy boundary, not a motion or heater controller. It verifies
immutable safety policy, blocks production-only forbidden commands, clamps
runtime limit increases, requires admitted read-only G-code snapshots, and
enforces the cleaned-and-rearmed build-plate state.

They provide `START_PRINT`, `END_PRINT`, `HOME_PRINTER`,

## Cleaned-and-rearmed behavior

The user requested a convenient checkmark-style workflow:

- The operator cleans the plate, fits the magnetic sheet, latches both rear
  clips, removes loose filament, clears the toolhead path, then presses
  `Cleaned and rearmed`.
- The state remains valid through harmless actions and successful idle homing.
  A successful X/Y-only home preserves it; any failed home clears it.
- The state is invalidated by print startup, any hot filament action, any
  extrusion or retraction command, purge, filament load or unload, `M600`,
  cancel, loaded-print command error, Klipper shutdown, or restart.
- The state cannot be set while a virtual-SD print is loaded or paused.
- The state cannot be set while the hotend has any target temperature or while
  the measured hotend temperature is at or above Klipper's configured
  `min_extrude_temp`.

Important limitation: this is not a real steel-sheet sensor. If a person removes
the sheet after confirming it, software cannot detect that. A physical
plate-presence sensor would be the only hardware-grade solution.

## Safety audit findings to preserve

- Ordinary Cancel can queue behind an active homing, probing, or temperature
  wait. Emergency Stop is the immediate unsafe-condition response.
- `M112` remains untouched and unconfirmed.
- Error paths must shut heaters down before optional parking, UI updates, or
  cleanup.
- Production blocks `FORCE_MOVE`, `SET_KINEMATIC_POSITION`, raw pins/heaters,
  raw TMC fields, shell commands, firmware/config writes, calibration writes,
  direct probe/debug commands, and manual motor release.
- The candidate starts with Comgrow's motion and current ceilings and lower
  temperature ceilings of `300 C` hotend and `100 C` bed.
- The full `9x9` mesh remains the default because the stock bed has shown more
  variation than a normal layer height. Adaptive mesh can be reconsidered only
  after the physical bed is improved and repeated full meshes prove the range
  is small enough.
- Camera, timelapse, USB, and network failure must disable those features, not
  interfere with Klipper, emergency shutdown, or print motion.
- The migration does not tune Frieren stringing by itself. Calibrate each
  filament in this order: temperature, maximum volumetric speed, pressure
  advance, flow ratio, then retraction. Drying or a known-good spool remains a
  later diagnostic if calibrated PLA still strings.
- A broad solid floor or deck transitioning to thin continuing walls now
  triggers a warn-first Orca Preview review for hull/floor lines. Layer time is
  a locator, not the diagnosis, and no strength- or geometry-affecting fix is
  applied automatically. The camera bracket has a concrete risk transition at
  `Z 1.20 mm`; Frieren has no automatic change.

## Next physical gates

Follow this sequence. The first two items are completed laptop-side
preconditions; the remaining items require the printer:

1. **Complete:** Keep the existing laptop-side printer USB backup and private
   GerGo material outside Git. The pinned recovery USB is prepared and locally
   verified.
2. **Complete:** Keep the official Comgrow `1.5.2` image, screen firmware, and
   integrated package in the private owner-only recovery directory. Their
   exact sizes and SHA-256 hashes are recorded in the Infrastructure and
   Recovery Dossier page.
3. Boot recovery from USB-C three times and prove MKS-Klipad50 identity,
   root-on-USB, unmounted eMMC, and direct Ethernet.
4. Capture and verify the full eMMC image.
5. Boot the mainline candidate from USB or recovery context with printer
   control disabled, then validate screen, touch, backlight, fan, network,
   camera, USB storage, services, and restart behavior.
6. Only after recovery and host validation, decide whether to write to eMMC.
7. Establish MCU communication without movement or heat.
8. Flash MCU firmware only after original recovery firmware and exact bootloader
   settings are proven.
9. Commission under attendance: sensors, endstops, probe, fans, one low-speed
    axis at a time, armed homing with the steel sheet installed, heaters one at
    a time, communication-loss shutdown, and Emergency Stop.
10. Recalibrate machine PID, extruder rotation distance, GerGo alignment, probe
    repeatability, Z offset, full mesh, and input shaping. Then calibrate each
    filament in the documented temperature, maximum-volumetric-speed, pressure-
    advance, flow-ratio, retraction order.
11. Validate a standard first-layer test, a small dimensional print, the orange
    camera bracket, a rendered timelapse, network/camera soak, and a rollback
    drill before considering Frieren again.
