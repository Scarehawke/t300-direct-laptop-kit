## Selected boot route

Kexec is rejected as the primary path. Do not deliberately make eMMC
unbootable. Use the screen's service USB serial connection and its normal
U-Boot USB path.

The console is fixed at 1,500,000 baud, 8N1, no flow control. The local helper
accepts only USB serial device names and sends nothing automatically:

```bash
python3 bin/t300-serial.py list
python3 bin/t300-serial.py console --device /dev/serial/by-id/EXACT_DEVICE
```

The owner interrupts U-Boot and types `run bootcmd_usb0`. The helper exits with
Ctrl-]. If the port, board identity, root device, or eMMC evidence differs from
the documented result, stop.

## Configuration state to preserve

- Production safety blocks bypass/debug controls and requires admitted,
  immutable G-code snapshots.
- Plate readiness is a human confirmation, not a physical sheet sensor.
- KAMP moving purge has no stationary prime; object data and a safe purge lane
  are mandatory.
- Pressure advance is bounded to `0..0.20` only during an admitted print and is
  reset during startup and cleanup.
- Stationary extrusion can only recover filament previously retracted by the
  same print.
- Full temperature-matched `9x9` meshing remains the default until the physical
  bed proves flatter.
- The exact purchased GerGo macro exists only in the owner-local maintenance
  stage. Its reviewed Z-stepper release is allowed there only; production and
  uploaded G-code still forbid motor-release commands.
- Orca projects remain editable and visibly calibration-required. Final G-code
  waits for machine commissioning and per-filament calibration.
- The physical display keeps the exact stock serial-TFT layout. Its vendor
  bridge is unprivileged and reaches Klipper only through a constrained
  loopback gateway. The first hidden startup `FIRMWARE_RESTART` is suppressed;
  explicit restart buttons retain their advertised behavior.
- All 77 physical controls have an explicit contract. The Macro page shows
  only `Printer Status`; dedicated Pause, Resume, Stop, and Change Filament
  controls are not duplicated there.
- Successful X/Y-only homing preserves plate readiness and cannot move Z. Any
  failed home invalidates readiness and leaves Klipper in error. Z-only and
  all-axis touchscreen homing require prior plate confirmation in Mainsail.
- Production Klipper uses `Restart=no` after an actual process crash. Explicit
  restart controls still work while Klipper is responsive.
